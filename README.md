# 🐛 ByteWorm Adventures: Monster Slayer

> **A "Bookworm Adventures" × Programming Trivia Combat RPG**  
> Battle animated software monsters, defeat compiler bugs, and conquer coding quizzes by forming programming keywords from randomized letter tiles!

---

## 🎮 How to Play

### 1. Launch the Game
The game is completely self-contained in a single file with zero build steps or package installations required!

- Click or double-click **`index.html`** in your browser, or:
- Open directly:
  ```text
  file:///C:/Users/USER/.gemini/antigravity-ide/scratch/byteworm-adventures/index.html
  ```

## ⚔️ Combat Scoring & Word Types

- **⭐ Target Trivia Solution (5x CRITICAL HIT):**
  Spelling the exact solution keyword for the current trivia question (e.g., `CONST`, `STACK`, `PROMISE`, `DOCKER`, `WHERE`) triggers an instant **5x Super Critical Strike** and obliterates the monster!
- **⚡ Programming Keywords (2.5x TECH COMBO):**
  Spelling any valid tech keyword or CS concept (e.g., `VAR`, `LET`, `FOR`, `ARRAY`, `OBJECT`, `PUSH`, `POP`, `NULL`, `TREE`, `QUERY`, `GIT`, `REST`) deals a **2.5x Tech Combo Damage**!
- **📖 Standard English Words (1x Damage):**
  Spelling any valid 3-8 letter English word (over 3,500+ common words supported) deals standard damage, guaranteeing you never get stuck.

## 🕹️ Controls & Hotkeys

| Control | Action |
| :--- | :--- |
| **Mouse Click / Tap** | Click any letter tile to add it to your word tray. Click an active word tile to remove it. |
| **Keyboard Typing** | Directly type letters `A-Z` on your keyboard to auto-select matching tiles from the grid. |
| **`[Enter]`** | **Compile & Attack**: Submits the word for evaluation and attacks the current monster. |
| **`[Backspace]`** | Undoes the last selected letter tile. |
| **`[Esc]`** | Clears the active word selection and returns all tiles to the grid. |
| **`[R]` / Reset** | **Git Reset**: Scrambles the board tiles when you are stuck. |
| **`[D]` / Lint** | **Debugger / Linter**: Analyzes the board and hints at the best tech words currently spellable. |
