HOW TO PLAY

1. The Mission

You are Lex the ByteWorm! Software monsters are corrupting the codebase. Each monster guards a programming quiz question and attacks if not defeated in time.

2. Monster Combat & Word Multipliers

Form words from the 16 letter tiles using either mouse clicks or keyboard typing.

  • Trivia Solution: Spells the exact answer to the question for 5x CRITICAL DAMAGE!
  • Programming Keywords: Words like VAR, INT, FOR, ARRAY, OBJECT, PROMISE, NULL, PUSH, POP deal 2.5x TECH COMBO!
  • Standard English Words: Valid English words deal normal 1x damage so you never get stuck!

3. Themed Monsters

Battle through distinctive software beasts: Syntax Bug Spider, Memory Leak Slime, Null Pointer Phantom, Infinite Loop Dragon, and the Deadlock Kraken!
